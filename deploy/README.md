# Долгая запись (этап 1)

| Файл | Для чего |
|---|---|
| `hftlab-recorder.service` | Linux/VPS: автозапуск и рестарт через systemd |
| `run_recorder.bat` | Windows: цикл перезапуска |

Проверка, что запись жива (раз в 5 минут через cron или планировщик):
```
python -m hftlab.health data
```
Код возврата 1 означает проблему (процесс умер, нет сети или кончается диск).
Пример cron-строки, которая пишет проблемы в файл:
```
*/5 * * * * cd /home/hft/hft-lab && PYTHONPATH=src .venv/bin/python -m hftlab.health data >> logs/health.log 2>&1
```

Объём: BTC+ETH дают порядка 1-2 ГБ gzip в сутки (оценка по первому часу записи, уточните на своих данных).
На 30 дней нужно 40-60 ГБ диска.

Если порт 8443 закрыт сетью, добавьте к команде рекордера `--url wss://ws.okx.com:443/ws/v5/public`.
